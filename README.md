# An Always Accepting Algorithm for Transition Path Sampling (AAA-TPS)
Companion repository for the paper "An Always Accepting Algorithm for Transition Path Sampling" aka "AAA-TPS"

## Installation
The necessary software for the execution of the notebooks and the instruction for its installation can be found in the folder `conda_envs`. In particular see the header of the file `spec-file_AROWS.txt`.
